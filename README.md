A [make.fun](https://make.fun/bounty/u-eager-stork-81-9647-funniest-lost-sock-status-update-4b1fa3ce) program/v1 entry for the **Funniest Lost Sock Status Update** bounty.

## What it does

`main.ts` (Node, no dependencies) writes a single status update — 118 characters,
in the voice of a lost sock — to `<output dir>/entry.txt`, with no trailing newline.

> Status: left in a limo, now the groom's emergency pocket square. If my argyle heel peeks out mid-vow, we're both dead.

## Run

```sh
node main.ts
```

The output directory comes from `MAKEFUN_OUTPUT_DIR`, else `MAKEFUN_OUTPUT`,
else `/output`.
